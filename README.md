# 컬러카드 배색 리더

제주 자연색 46색 컬러카드(뚜띠콜로리 · 컬러헌팅 TC 인덱스)의 인덱스 번호를 최대 다섯 개까지 넣으면,
각 색이 지닌 의미와 다섯 색이 함께 만드는 배색 형태·색채조화를 읽어 주는 웹 도구입니다.

## 하는 일

- **배색 형태 판정** — Complementary, Split-Complementary, Analogous, Triadic, Tetradic, Square, Monochromatic
- **톤 관계 판정** — Tone on Tone, Tone in Tone, Camaïeu, 명도 대비, 채도 대비
- **의미 해석** — 46색 키워드를 활력·안정·감성·이성 네 축으로 집계
- **면적비 제안** — 채도 순으로 지배 60 / 보조 30 / 강조 10 배정
- **보완색 추천** — 비어 있는 보색·분리보색 자리와 무채축을 채울 카드 제시
- **배색 저장** — 워크숍 조별 결과를 이름 붙여 보관 (브라우저에 저장)
- **색 견본 보정** — 인쇄 카드 실측 HEX를 넣으면 화면 색과 톤 계산에 반영

## 판정 원리

TC 인덱스는 `색상군(2자) + 명도(1자) + 채도(1자)` 구조로 읽습니다.

| 부분 | 예 (`BG56`) | 해석 |
|---|---|---|
| 색상군 | `BG` | 10색상환에서 청록, 180° |
| 명도 | `5` | L\* ≈ 57 |
| 채도 | `6` | 해당 색상군 최대 채도의 약 70% |

색상군은 `RR·YR·YY·GY·GG·BG·BB·PB·PP·RP` 열 개를 36° 간격으로 배치합니다.
`ER`(갈색)은 저채도 난색으로 18°에, `NN`(무채색)과 `NE`(한색 기미 중성)는 무채축에 둡니다.
선택한 색들의 색상 간격을 계산해 배색 형태를 가르고, 명도·채도 분포로 톤 관계를 겹쳐 판단합니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 빌드해 GitHub Pages로 올립니다.
저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 한 번 바꿔 주세요.
`vite.config.js` 의 `base: "./"` 덕분에 저장소 이름이 무엇이든 그대로 동작합니다.

## 색 견본에 관하여

기본 견본은 TC 인덱스에서 역산한 근사값입니다.
인쇄 카드의 실측값은 앱의 **색 견본 보정** 탭에서 HEX로 넣으면 되고,
전체를 고정하려면 `src/App.jsx` 의 `CARDS` 배열 각 항목에 `hex: "#xxxxxx"` 를 추가하면 됩니다.
