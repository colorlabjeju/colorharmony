# 익명 집계 설치 안내

고른 카드와 배색 형태를 익명으로 모아 구글 시트에 쌓는 절차입니다.
개인을 식별하는 값은 보내지 않습니다. 이름, 연락처, 메모 내용은 수집 대상이 아닙니다.

전체 20분 정도 걸립니다. 1~4단계는 한 번만 하면 됩니다.

---

## 무엇이 쌓이는가

사람이 버튼을 누른 순간에만 한 줄이 기록됩니다. 화면을 보기만 하면 아무것도 보내지 않습니다.

| 이벤트 | 언제 | 쌓이는 것 |
|---|---|---|
| `read` | 배색조화 확인하기를 누를 때 | 고른 카드, 배색 형태, 톤, 한난, 워크숍 코드 |
| `accept_fix` | 보완 제안 카드를 누를 때 | 어떤 카드를, 어떤 상황에서 받아들였는지 |
| `accept_tip` | 한 장 더 얹기 카드를 누를 때 | 같음 |
| `keyword` | 키워드 제안을 이 배색으로 읽기로 넘길 때 | 고른 키워드, 자유 입력한 말, 채택한 배색 |

세션 값은 브라우저마다 무작위로 만든 여덟 자리입니다. 같은 사람이 여러 번 썼는지 세는 용도이고,
그 값으로 누구인지는 알 수 없습니다.

---

## 1. 구글 시트 만들기

1. 구글 드라이브에서 새 스프레드시트를 하나 만듭니다.
2. 이름은 `컬러카드 배색 리더 — 수집` 정도로 둡니다.
3. 시트는 비워 둡니다. 머리글은 첫 수신 때 자동으로 생깁니다.

## 2. 앱스 스크립트 붙이기

1. 그 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본으로 열린 `Code.gs`의 내용을 전부 지웁니다.
3. 이 폴더의 `apps-script/Code.gs` 내용을 통째로 붙여 넣습니다.
4. 저장합니다. 프로젝트 이름은 아무거나 괜찮습니다.

## 3. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴를 눌러 유형을 **웹 앱**으로 고릅니다.
3. 설정을 이렇게 둡니다.
   - 설명: 아무거나
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누릅니다. 처음에는 권한 승인 창이 뜹니다. 본인 계정으로 허용하면 됩니다.
   "이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → 안전하지 않은 페이지로 이동**을 누릅니다.
   본인이 만든 스크립트라 정상입니다.
5. 끝나면 **웹 앱 URL**이 나옵니다. `https://script.google.com/macros/s/…/exec` 형태입니다.
   이 주소를 복사해 둡니다.

> **액세스 권한을 "모든 사용자"로 둬야 합니다.** 참가자들이 구글 로그인 없이 쓰기 때문입니다.
> 이 설정은 누구나 데이터를 *보낼 수* 있다는 뜻이지, 시트를 *볼 수* 있다는 뜻이 아닙니다. 시트는 그대로 비공개입니다.

## 4. 주소를 앱에 넣기

`src/App.jsx`를 열고 위쪽에서 이 줄을 찾습니다.

```js
const ENDPOINT = "";
```

따옴표 안에 3단계에서 복사한 주소를 넣습니다.

```js
const ENDPOINT = "https://script.google.com/macros/s/AKfy…/exec";
```

비워 두면 수집은 꺼진 상태로 동작합니다. 안내 문구의 수집 고지도 함께 숨겨집니다.

## 5. 배포하기

변경한 파일을 깃허브에 올리면 끝입니다.

```bash
git add -A
git commit -m "익명 집계 추가"
git push
```

깃허브 웹에서 고치신다면 `src/App.jsx`를 열어 연필 아이콘을 누르고 그 한 줄만 바꾼 뒤 저장하면 됩니다.
1~2분 뒤 자동으로 반영됩니다.

## 6. 확인하기

1. 배포된 페이지를 엽니다.
2. 카드를 두세 장 고르고 **배색조화 확인하기**를 누릅니다.
3. 구글 시트의 `수집` 탭에 줄이 하나 생겼는지 봅니다.

줄이 안 생기면 아래 **막힐 때**를 보세요.

---

## 워크숍에서 쓰는 법

입력창 줄 맨 앞에 **워크숍 코드** 칸이 있습니다. 여기에 `251015-함덕` 처럼 적어 두면
그 뒤의 모든 기록에 따라붙습니다. 한 번 적으면 그 기기에 남아서 다시 칠 필요가 없습니다.

행사마다 다른 코드를 쓰면 나중에 시트에서 행사별로 갈라 볼 수 있습니다.

---

## 집계 보기

Apps Script 편집기에서 함수 목록에서 `집계만들기`를 고르고 실행하면
`집계` 탭이 만들어집니다. 이런 것들이 정리됩니다.

- 판독 횟수와 추천 카드 수락 횟수
- 46색 중 무엇이 몇 번 선택되었는지
- 배색 형태가 어떻게 분포하는지
- 사람들이 어떤 키워드를 골랐는지

매일 자동으로 돌리려면 편집기 왼쪽의 시계 아이콘(트리거)에서
`집계만들기`를 일 단위로 걸어 두면 됩니다.

## 막힐 때

**시트에 아무것도 안 쌓입니다**
→ 웹앱 URL이 `/exec`로 끝나는지 봅니다. `/dev`로 끝나면 로그인한 사람만 쓸 수 있어서 참가자 기록이 들어오지 않습니다.
→ 배포 설정의 액세스 권한이 **모든 사용자**인지 다시 확인합니다.
→ 브라우저에서 그 URL을 그냥 열어 봅니다. `{"ok":true,"note":"collector alive"}`가 보이면 서버 쪽은 정상입니다.

**코드를 고쳤는데 반영이 안 됩니다**
→ 앱스 스크립트는 저장만으로는 배포에 반영되지 않습니다. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 합니다. URL은 그대로 유지됩니다.

**숫자가 실제보다 많아 보입니다**
→ 같은 사람이 카드를 바꿔 가며 확인하기를 여러 번 누르면 그만큼 쌓입니다.
세션 값으로 중복을 걸러 세면 사람 수에 가까워집니다.

---

## 수집을 멈추려면

`src/App.jsx`의 `ENDPOINT`를 다시 빈 문자열로 바꾸고 올리면 즉시 멈춥니다.
앱스 스크립트 쪽에서는 **배포 → 배포 관리 → 보관처리**로 끌 수 있습니다.
